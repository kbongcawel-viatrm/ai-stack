# Shared agent skills

Reusable skills live here as directories containing a `SKILL.md`. Keep each skill scoped to one repeatable workflow. Use standard frontmatter fields `name` and `description`; include prerequisites, safe execution steps, validation, and references.

Cline-specific skills are mirrored under `.cline/skills/` where appropriate so Cline's project skill loader can discover them. Avoid duplicating long instructions: link to the canonical shared skill when a tool supports that layout.
