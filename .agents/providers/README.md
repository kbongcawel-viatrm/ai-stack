# Provider configuration index

Provider credentials are created outside Git and configured in the client/runtime. Store only non-secret metadata and setup docs here.

| Provider path | Intended use |
|---|---|
| [Cline API](cline-api.md) | OpenAI-compatible HTTP Chat Completions endpoint |
| [Cline CLI](cline-cli.md) | Terminal agent installation, authentication, and smoke test |

Use official docs for model IDs, auth methods, data residency, usage, and pricing; these can change. Never commit a real API key.
